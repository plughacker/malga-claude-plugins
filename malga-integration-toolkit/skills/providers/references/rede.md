# Rede

Reference summary derived from `documentations/providers/rede.mdx`. Official page: <https://docs.malga.io/documentations/providers/rede>.

Legend: **✓** supported by Malga · **✗** not supported by the provider · **—** offered by the provider but not yet wired up in Malga's API (contact suporte@malga.io to request).

A Rede é pioneira em meios de pagamento online no Brasil, oferecendo serviços para transações com cartões de crédito desde 1996. Parte do grupo Itaú, é referência em confiabilidade e suporte às lojas.
[Mais informações.](https://developer.userede.com.br/)
