# Zoop

Reference summary derived from `documentations/providers/zoop.mdx`. Official page: <https://docs.malga.io/documentations/providers/zoop>.

Legend: **✓** supported by Malga · **✗** not supported by the provider · **—** offered by the provider but not yet wired up in Malga's API (contact suporte@malga.io to request).

Operando desde 2013, a Zoop oferece diversas soluções de pagamento para e-commerces e marketplaces, incluindo processamento de crédito, PIX, boleto e Split, reconhecida pela flexibilidade de seus serviços financeiros como provedor de pagamento.
[Mais informações.](https://docs.zoop.co/)
