# SafraPay

Reference summary derived from `documentations/providers/safrapay.mdx`. Official page: <https://docs.malga.io/documentations/providers/safrapay>.

Legend: **✓** supported by Malga · **✗** not supported by the provider · **—** offered by the provider but not yet wired up in Malga's API (contact suporte@malga.io to request).

Em operação desde 2014 e parte do grupo Safra, a SafraPay atua em soluções como provedor de pagamento por cartão de crédito e PIX, oferecendo tecnologia para lojas processarem vendas com segurança.
[Mais informações.](https://www.safrapay.com.br/venda-online/api-ecommerce.html)
