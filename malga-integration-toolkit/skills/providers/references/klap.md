# Klap

Reference summary derived from `documentations/providers/klap.mdx`. Official page: <https://docs.malga.io/documentations/providers/klap>.

Legend: **✓** supported by Malga · **✗** not supported by the provider · **—** offered by the provider but not yet wired up in Malga's API (contact suporte@malga.io to request).

A Klap atua como provedor de pagamentos por cartão de crédito no Chile, oferecendo suporte a diferentes moedas para América Latina. Disponibiliza recursos com facilidade de uso e segurança para operações internacionais.
[Mais informações.](https://www.klap.cl/developers/docapi)
